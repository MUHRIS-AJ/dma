# Campaign and conversion plan

## Honest launch content

Publish only owner-approved instructor profiles, student stories, certificates and partner marks. Results areas should show practical deliverables until real outcomes can be substantiated. No fabricated graduate counts, employment rates or testimonials should be introduced to improve apparent trust. Confirm curriculum and delivery details before running paid acquisition.

## Message-matched landing pages

Each course route is a distinct campaign landing page, with its own curriculum, direct answers, project outcome, metadata and social image. Link ads to the relevant detail page rather than sending every audience to the homepage. Add standard UTM values; existing links should preserve them through course selection.

| Ad group | Landing page | Intent and opening message |
| --- | --- | --- |
| UI/UX foundations | `/courses/ui-ux/` | Turn user needs into a usable website prototype |
| Organic search | `/courses/seo/` | Build a practical search and content strategy |
| Website audits | `/courses/technical-seo/` | Understand crawling, indexing and performance |
| AI search discovery | `/courses/aeo-geo/` | Make information clear for search and answer engines |
| Measurement | `/courses/google-analytics/` | Translate website behavior into better questions |
| Landing-page improvement | `/courses/cro/` | Find friction and plan meaningful experiments |
| Paid and social growth | `/courses/sem-smm/` | Connect audience, creative and measurement |

Example: `/courses/technical-seo/?utm_source=google&utm_medium=cpc&utm_campaign=technical_seo&utm_content=audit_project&utm_term=technical_seo_course`. Use platform macros only after validating their syntax in the chosen platform. Do not place personal information in campaign URLs. Canonicals intentionally exclude tracking parameters.

Social images are generated as 1200 × 630 PNG files in `/og/`. Preview each link before a campaign goes live. A configured but inactive Meta Pixel placeholder does not create remarketing audiences.

## Hero A/B tests

Run tests sequentially so headline and CTA effects can be distinguished. Keep audience, page layout and traffic allocation stable within each experiment. Persist a visitor's assignment, exclude team traffic, and record an experiment identifier and variant after consent. This document is a test plan; no assignment service is currently claimed to be implemented.

| Test | A | B | Hypothesis |
| --- | --- | --- | --- |
| Headline | Build your digital edge. | Learn digital skills. Make real things. | A more explicit practical outcome may improve qualified course exploration |
| CTA | Explore the courses | Find my learning path | A choice-oriented invitation may lower uncertainty for first-time learners |

The primary metric is verified qualified enquiries per eligible session once a delivery endpoint exists. Until then use completed course exploration as a diagnostic, never a proxy for sales. Secondary measures: course views, CTA activations and confirmed form delivery. Guardrails: mobile performance, abandonment, duplicate enquiries and enquiry quality. Define baseline, minimum detectable effect, power and sample size before launch; avoid selecting a winner from daily fluctuations. Run through complete weekly cycles and review uncertainty, not just uplift.
